# Повторная визуальная сверка · 22 ноября 2026

Первый проход не подтверждал полное совпадение с HTML. Повторная проверка расширена
до 15 состояний Flutter и 12 состояний HTML с одинаковыми локальными шрифтами,
датой 15.12.2026 12:00 Europe/Moscow и reduced motion. Это инженерная сверка,
не окончательная визуальная приёмка автора и не испытания физического телефона.

## Что обнаружено и исправлено

| Расхождение | Исправление |

| Не перенесены последние поправки арта | Позиции/масштаб 2, 9, 25, 31 декабря и отдельные размеры подписей 1, 8, 14, 31 повторяют финальные CSS-правила |
| Слишком крупные обычные даты на узком экране | Размер цифр зависит от ширины как в CSS clamp; состояния прошлого/будущего различают opacity, saturation и brightness |
| Резкий прямоугольник затемнения у hero | Вертикальная маска верхнего/нижнего края; возвращены два декоративных символа |
| Короткий совет занимал почти весь экран | Шторка имеет естественную высоту, ограниченную 91% viewport |
| Заголовок длинной шторки оставался закреплён | Прокручивается вместе с содержимым; постоянны только ручка и кнопка закрытия |
| Арт события, поля, подписи и интервалы отличались | Отдельные градиенты sheet, арт 188 в области 174, фактура; метаданные и разделитель по эталону |
| Совет имел другое начертание и лишнюю обводку share | Жирная цитата, letter-spacing, текстовое вторичное действие и исходные интервалы |
| История декабря была текстовой заглушкой | Восстановлены счётчик открытий, визуальный countdown, пояснение и «Понятно!» |
| Нижний блок был центрированным заголовком | Восстановлена панель с градиентом, рамкой, исходной типографикой и декоративной звездой |

| Сравнивались разные прокрутки под шторкой | В сценарии синхронизировано положение страницы для коротких событий/советов и истории |

## Матрица кадров

- Календарь: 320 / 360 / 390 / 430 dp, состояние прогресса сбрасывается перед каждым размером.
- Конец месяца: 320 / 390 dp, включая будущие советы, арт 25/31 и нижнюю панель.
- Середина: 390 dp, текущая дата 15 и будущие замороженные карточки.
- Короткое событие, совет и история: 390 dp.
- Длинное событие 11 декабря: 320 dp, начало и конец прокрутки.
- Текст 200%: 320 dp, календарь и длинное событие в начале/конце.

В визуальном тесте проверяются отсутствие ошибок layout, достижимость share в конце
длинного текста и доступность закрытия после прокрутки. Одинаковая зона браузера и
кампании позволяет проверять countdown без случайного смещения на часы устройства.

## Воспроизведение и отчёт

CI создаёт artifact advent-visual-review: index.html с парными кадрами и все оригинальные
PNG без потерь. tools/visual-report.py генерирует этот отчёт; в логах остаются компактные
JPEG-превью и одна точная PNG-пара. Ограничение логов не меняет сохранённые PNG.

Локальные команды при установленном Flutter:

1. Из flutter/: flutter test --dart-define=ADVENT_VISUALS=true test/visual_test.dart.
2. Из корня: tools/visual-reference.cjs с Playwright/Chromium.
3. Из корня: python tools/visual-report.py с Pillow.

На Linux headless CI использует fonts-noto-color-emoji. Этот системный шрифт нужен
снимкам и не включается в APK. На других системах тесту следует предоставить emoji
font либо отдельно проверять штатный fallback платформы.

## Что остаётся за пределами проверки

Физические Android/iOS, разные GPU/DPR и системные safe areas, screen reader,
фактические native share/calendar и их отмена/отказ. Между Flutter/Chromium остаются
мелкие различия сглаживания и метрик шрифтов; окончательную приёмку по снимкам нельзя
подменять утверждением о pixel-perfect на всех устройствах. Набор данных, часы,
платформенные контракты и исходный index.html этим проходом не изменены.
