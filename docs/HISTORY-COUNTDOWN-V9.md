# Новогодний счётчик истории · финальная доводка v9

24 ноября 2026, PR #6. По последнему согласованному визуальному запросу меняется только оформление обратного отсчёта внутри «Твоей истории декабря».

- Вместо отдельной обрезанной 3D-ёлки — существующий `entry_fir_v9.webp` на весь фон, `BoxFit.cover`, естественные пропорции, alignment centerRight, opacity .90. Поверх мягкий зелёный градиент для контраста; внешний радиус 18 dp и прежняя геометрия, включая отступ границы, сохранены.
- Четыре отдельные матовые плитки: blur 9/9, зелёная заливка `#102E25` alpha 35%, светлая обводка 1 dp `#F5F5DE` alpha 22%, блик из v9, радиус 16 dp. Параметры точно совпадают с входным календариком. Входная карточка и её исходник **не изменены**. Заливка и блик отрисовываются отдельными слоями, числа/подписи находятся вне фильтра.
- Сохранены Yeseva One 36 dp, золотые числа, подписи и все тексты, четыре колонки при обычном масштабе и две при scale > 1.4. Фон не дублируется в assets и не растягивается.
- Таймер 1 секунда и прежняя формула `TZDateTime(location, 2027).difference(clock.nowUtc()).inSeconds`, разбиение значений и padLeft(2), московский пояс и нулевое/праздничное состояние сохранены. Таймер локализован внутри счётчика: остальные блоки истории больше не перестраиваются каждую секунду. Постоянный фон — отдельный const RepaintBoundary вне ValueListenableBuilder; цифры имеют собственные границы перерисовки.
