# Новогодний счётчик истории · финальная доводка v9

24 ноября 2026, PR #6. По последнему согласованному визуальному запросу меняется только оформление обратного отсчёта внутри «Твоей истории декабря».

- Вместо отдельной обрезанной 3D-ёлки — существующий `entry_fir_v9.webp` на весь фон, `BoxFit.cover`, естественные пропорции, alignment centerRight, opacity .90. Поверх мягкий зелёный градиент для контраста; внешний радиус 18 dp и прежняя геометрия, включая отступ границы, сохранены.
- Четыре отдельные матовые плитки: blur 9/9, зелёная заливка `#102E25` alpha 35%, светлая обводка 1 dp `#F5F5DE` alpha 22%, блик из v9, радиус 16 dp. Параметры точно совпадают с входным календариком. Входная карточка и её исходник **не изменены**. Заливка и блик отрисовываются отдельными слоями, числа/подписи находятся вне фильтра.
- Сохранены Yeseva One 36 dp, золотые числа, подписи и все тексты, четыре колонки при обычном масштабе и две при scale > 1.4. Фон не дублируется в assets и не растягивается.
- Таймер 1 секунда и прежняя формула `TZDateTime(location, 2027).difference(clock.nowUtc()).inSeconds`, разбиение значений и padLeft(2), московский пояс и нулевое/праздничное состояние сохранены. Таймер локализован внутри счётчика: остальные блоки истории больше не перестраиваются каждую секунду. Постоянный фон — отдельный const RepaintBoundary вне ValueListenableBuilder; цифры имеют собственные границы перерисовки.

## Файлы и границы изменения

- `flutter/lib/src/ui/history_countdown.dart` — отдельный part с новым оформлением; `calendar_screen.dart` только подключает его вместо прежнего встроенного блока и переносит туда секундный таймер.
- `flutter/test/history_countdown_test.dart` — реальные шрифты, 320/360/390/430 dp, text 100/200%, 4/2 колонки, границы чисел, четыре clipped blur без текста, точные значения, переход 20:59:59 → 21:00:00 UTC (московская полночь Нового года) и отсутствие повторной отрисовки фотографии при тике.
- Android integration/driver сохраняют PNG с настоящего Android-renderer при 100/200% после прежних motion-проверок, не влияя преобразованием поверхности на их измерения. Отдельные headless-снимки восьми состояний — artifact `advent-history-countdown-review`; Android PNG — `advent-android-motion`.
- README и ROADMAP фиксируют последний визуальный шаг. Прогресс, saved advice, остальные блоки истории, жесты, данные 31/14/17, HTML и backend не менялись.

## Результат

Проверки CI и Android-снимки ожидаются. Прямой APK будет опубликован существующим механизмом Releases после полного успеха CI; кнопки README main/feature обновятся автоматически. PR #6 не сливается.

После успешной проверки этот согласованный шаг завершает визуальный этап. Далее — тестирование, оптимизация, подтверждение контента, интеграция и выпуск. Новые визуальные изменения без отдельного решения автора не инициируются. Проверка скорости на физическом телефоне относится к технической QA, а не к новой дизайн-итерации.
