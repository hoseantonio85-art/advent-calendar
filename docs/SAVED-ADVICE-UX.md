# Сохранённые советы · UX/UI и контракт для Flutter

**Зафиксировано:** 23 ноября 2026  
**Статус:** реализовано в каноническом HTML; **во Flutter ещё не перенесено**.  
**Визуальный эталон:** [index.html](../index.html) / [GitHub Pages](https://hoseantonio85-art.github.io/advent-calendar/?preview=31).  
**Коммит HTML:** [9a2cf51](https://github.com/hoseantonio85-art/advent-calendar/commit/9a2cf510ba201fc432c54862b267e7ce3a4a4daa).

## Почему меняем

Ранее «Сохранить совет» меняло надпись кнопки и localStorage, но пользователь после закрытия шторки не видел результата. При этом открытые дни и сохранённые советы — **независимые состояния**. Лайки, рейтинг, публичный счётчик не возвращаются.

## Согласованная механика

1. В шторке доступного дня с **советом** основная кнопка «Сохранить совет» имеет контурное сердечко.
2. По нажатию совет добавляется в личное сохранённое. Кнопка меняется на «Совет сохранён» с заполненным сердцем; повторное нажатие отменяет сохранение. Кнопка показывает toggled/pressed-state.
3. На карточке соответствующей даты в Bento-сетке появляется **маленькое заполненное сердечко**, не изменяющее её геометрию. Сердце не добавляется к мероприятиям, не отображается на закрытом будущем совете, не конкурирует с текущей золотой обводкой. Для screen reader состояние включается в название карточки.
4. В существующей шторке **«Твоя история декабря»** после счётчика и новогоднего countdown появляется секция **«Сохранённые советы»** с числом сохранений. Не создавать другой экран или вложенную шторку.
5. Если сохранений нет — компактное пустое состояние с объяснением. Если есть — список по возрастанию даты; каждая строка содержит заголовок совета, дату и chevron.
6. При нажатии на строку **прямо под ней раскрывается** исходный текст совета и пункт «Попробуй сегодня». Использовать native details/accordion — без нового перехода назад. При свёртывании подробности скрываются.
7. Если сохранено больше 3 советов, сначала показаны первые 3 по календарной дате; «Показать все N» раскрывает остальные. После раскрытия «Свернуть» вновь оставляет первые 3; раскрытые дополнительные записи закрываются.
8. Сохранение **не увеличивает** «Открыто X / 31». Счётчик обновляется только при открытии доступной даты.
9. В HTML сохраняем прежний ключ `advent2026-saved` и восстановление после перезагрузки; не обнуляем существующий пользовательский выбор.

## Особые случаи

- Всего 31 день, 14 мероприятий, 17 дней с советами на 23.11.2026. Совет хранится в данных всех 31 дней, но кнопка сохранения доступна только на днях, показывающих совет. Если день преобразован в мероприятие (например, 19 декабря), сохранённый ранее совет этого дня не выводится в избранном, пока это мероприятие.
- Прогресс, добавление событий в календарь, системный share, свайп за ручку, Android Back, визуал заморозки, анимации и доступность дат не меняются.
- HTML не синхронизирует сохранённое состояние между браузерами и Flutter: у Flutter собственный `SavedAdviceRepository`. Не обещать общий серверный список без backend.
- HTML QA: `?preview=31` раскрывает все обычные советные дни; параметр не переносится в production Flutter.

## Перенос во Flutter · отдельная задача

Использовать существующие `SavedAdviceRepository` и локальный scoped adapter в `flutter/lib/src/platform/local_repository.dart`, `AdventCalendarScreen` / `_DaySheet` в `flutter/lib/src/ui/calendar_screen.dart`. Сейчас сохранение во Flutter есть **внутри шторки**, но `_CalendarState` не отображает сохранённые id на Bento-сетке, а шторка истории не показывает их списком.

Добавить в Flutter:
- загрузку сохранённых id на уровне экрана, not just day sheet;
- обновление маркера непосредственно после сохранения/отмены без повторного открытия страницы;
- компактные сердечки в нативных карточках советов (только доступные и сохранённые);
- секцию в существующем history bottom sheet, inline-expansion и `show all`;
- сохранение счётчика и системных действий без изменений; тесты и визуальную сверку с HTML.

Никаких лайков, серверов, новых страниц, nested modals или вторых HTML-прототипов.

## Критерии проверки

- [ ] 0 сохранений: понятное пустое состояние, 0 в счётчике.
- [ ] 1 сохранение: заполненный heart на дате и в кнопке, после обновления страницы остаётся.
- [ ] 4+ сохранения: 3 строки + «Показать все N»; раскрытие/сворачивание, клавиатура.
- [ ] Удаление: маркер исчезает сразу; после нового открытия истории список актуален.
- [ ] Нет маркера на мероприятии/закрытой дате, сохранение не влияет на прогресс 31.
- [ ] Шторки закрываются свайпом вниз, focus/Back работают.
- [ ] Flutter scoped хранение не смешивает пользователей; после восстановления/логина отображение актуально.
- [ ] Сверить на мобильных ширинах 320/360/390/430dp, увеличение шрифта и reduced motion.
