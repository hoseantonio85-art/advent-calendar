# Нативный календарь · Issue #2

Реализован отделяемый Flutter-package с автономным demo. Публичный
AdventCalendarScreen открывается полноценным маршрутом; события и советы —
в отдельных шторках. index.html и GitHub Pages сохранены без изменений.

Экран принимает content/time/progress, optional actions/savedAdvice/onExit.
Использует единый проверенный набор 31 дня (13 мероприятий, 18 советов), исходные
WebP, offline Yeseva One и Roboto с OFL. Трёхколоночная Bento-сетка использует
row-flow и широкие карточки из контента, высоты 104/111/124 dp и gap 5/6/8 dp.
Увеличение текста увеличивает высоту карточек. Шрифты изолированы от темы хоста.

Есть будущие/прошлые/текущие даты, замороженные советы, снег и орнамент,
анимированный золотой контур и 9-секундное дыхание hero. Reduced motion
останавливает анимации. Таймер московской полуночи и resume обновляют дату.
Прогресс учитывает только уникальные открытия доступных дней. Ошибки загрузки,
сохранения и действий обработаны. Пока сохранённые советы загружаются,
кнопка сохранения отключена; после ошибки предлагается повторить загрузку.

Demo: v9 → календарь → детали → назад. Прогресс и сохранённые советы
восстанавливаются через SharedPreferencesAsync в отдельном локальном scope.
Share вызывает ОС. Calendar на Android/iOS показывает подтверждение исходных
данных и открывает редактор; без часов — только явно выбранная дата all-day.
Сервер и синхронизация не создавались. [Контракты](PLATFORM-INTEGRATION.md).

## Визуальная сверка

Получены снимки настоящего Flutter-рендера и исходного HTML с одинаковой датой
15.12.2026, viewport 390×844 и reduced motion. После сравнения исправлены:
обрезка верхушки/положение ёлки, отступы и геометрия панели прогресса, её медаль,
полная ширина заголовка события, отдельная закреплённая кнопка закрытия,
карточки даты/времени/места, форма кнопок и шрифт их подписей. Высота шторки —
91% по эталону. Поправлено тестовое окружение загрузки арта в overlay и иконок.
Это первый инженерный проход сверки, не финальная визуальная приёмка автора.

Снимки создаются только в CI/тестах: четыре ширины календаря, событие и совет;
исходный HTML снимает Chromium. Метки ADVENT_PNG в QA-логах позволяют восстановить
PNG. Дата теста не передаётся в production, QA-переключателей в приложении нет.

## Проверки и запуск

CI: проверка точности контента/арта, flutter analyze пакета/demo, 17 unit/widget
тестов, отдельный визуальный тест, web build и Android debug APK. APK публикуется
как artifact advent-demo-debug-apk, а не как production-релиз или GitHub Pages.

Локально: cd flutter/example, flutter pub get,
flutter create --platforms=web,android,ios --project-name advent_demo .,
flutter run. Сгенерированные платформенные файлы — demo-хост, не feature-код.
