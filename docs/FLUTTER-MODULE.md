## Данные и происхождение

JSON — единственный источник production-контента Flutter. HTML остаётся неизменным
зафиксированным визуальным эталоном и веб-прототипом; Flutter не исполняет его.
31 запись: 13 event, 18 advice. Все 31 исходные тройки thoughts сохранены в advice,
включая скрытые в HTML советные тексты на датах мероприятий. События сохраняют
все исходные поля дословно: title, shortTitle, cardLines с NBSP, desc с Markdown,
cta при наличии, art/theme, time/duration/place, sourceCopy при наличии.
Новые поля: стабильный id, ISO date, kind, columns (1 или 2), locations (разделение
исходного place по «; »), startTime (null для «Не указано»/«В течение дня»), verification.
Исходное time не заменено машинным полем; отсутствие часов не означает подтверждённое all-day.
Для системного экспорта без времени требуется решение пользователя/хоста.
В assets/advent/art лежат 16 точных декодированных WebP из HTML с учётом поздних
переопределений champagne/citrus/moneybag и hero_tree из шапки.
Советные карточки в сетке остаются без подписи и арта: поле art для их шторок.

Все мероприятия имеют verification=requiresConfirmation: перенос доказывает совпадение
с прототипом, но не достоверность расписания. sourceCopy=true оставлено только там,
где этот маркер присутствовал в HTML (4, 9, 11, 15). Время отсутствует на 4, 9, 11, 15,
на 25 — «В течение дня». Остальные часы, длительности и места не подтверждены заново.
11 и 15 — отдельные намеренно повторяющиеся мероприятия, не дубликаты id.
Ничего не уточняли и не придумывали. node tools/verify-content.cjs сравнивает все
поля, расположение и байты графики с HTML и должен оставаться зелёным.

## Время и прогресс

Хост явно передаёт AdventClock и tz.Location. Нет fallback на зону устройства.
Хост предварительно вызывает initializeTimeZones из timezone/data/latest.dart.
Europe/Moscow — подтверждённая автором зона кампании (22.11.2026).
Для кампании использовать CampaignTime.moscow(clock: clock). Конфигурируемый
конструктор сохранён для тестов и повторного использования с другими IANA-зонами.
Дата — civil date в зоне кампании; сравниваются год, месяц, день, а не число декабря.
Мероприятия доступны всегда. Совет открывается с 00:00 своей даты и остаётся доступен
после кампании. До декабря доступны только мероприятия. После 1 января доступны все дни.
Счётчик входа — календарные дни до 01.01.2027 в этой же зоне, минимум 0.

Прогресс — множество id доступных открытых дней, максимум 31. Неизвестные id и будущие
советы из повреждённого/внешнего состояния исключаются при чтении. Дубли не увеличивают
счётчик. Хранилище обязано выполнять атомарное set-union в recordOpened, изолировать
пользователей и кампании. Это предотвращает потерю параллельных открытий. Хранилище
не должно принимать id из других источников без валидации. При переводе часов назад
будущие советы перестают учитываться, их сохранённые id остаются в хранилище.
