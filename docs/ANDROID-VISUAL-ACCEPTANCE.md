## Технические границы

CSS inset shadow/frost и blur светового пятна аппроксимированы градиентами/векторными
слоями без отдельных offscreen blur для каждой плитки. Настоящий backdrop blur есть
на единственной панели истории и существующих подписях сюрпризов. CSS saturate(1.15)
именно фона панели отдельно не воспроизводится. Шрифтовое сглаживание Chromium и
Flutter/Android может различаться. Это не обещание pixel-perfect на всех GPU.

Android-эмулятор проверяет настоящий Android runtime, но не физический телефон.
FrameTiming из debug/software GPU диагностический и не доказывает 60 fps на телефоне;
окончательная плавность, TalkBack и производительность требуют просмотра нового APK
автором на устройстве. Слияние PR и публикация сайта не выполнялись.

## Итог Android runtime и производительность

Полный сценарий прошёл на Android API 35: XXS, верхнее уведомление для совета и
сюрприза, повторный тап, отсутствие раннего прогресса, появление шторки, непрерывный
свайп за ручку, Back, крестик и reduced motion. Кадры собирались после каждого
реального рендера, а не одиночными запоздавшими замерами после ожидания. Видео
скачано и просмотрено последовательностью кадров, включая открытие и закрытие.

Наблюдаемые верхние координаты шторки: 640 → 437,94 → 104,28 → 58,32 → 57,60 dp.
Контроллер имеет 420 ms открытия; отдельно unit-тест проверяет его промежуточные
позиции и 300 ms закрытия. В режиме reduced motion переход отключён.

Сохранено 257 FrameTiming. Debug / software GPU / Skia: P95 build 86,0 ms, raster
124,3 ms; средние 33,2 / 98,1 ms, максимумы с холодным запуском 513,0 / 3878,9 ms.
Это **не 60 fps на эмуляторе** и не измерение производительности телефона: в запись
входят запуск, загрузка арта, тестовый драйвер и программный GPU. Performance-приёмка
остаётся открытой до profile-сборки на физическом устройстве. Проверка подтверждает
поведение и фактическое движение в Android; плавность на всех устройствах не обещана.

Для снижения стоимости эффекты плиток используют аналитические градиенты и
векторную кромку без отдельных blur-слоёв; настоящее размытие ограничено панелью
истории и существующими небольшими подписями сюрпризов. HTML, контент/правила,
сохранённые советы и конфетти этим этапом не изменены.
