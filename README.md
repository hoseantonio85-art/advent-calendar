# Декабрь чудес · Advent Calendar

Интерактивный мобильный HTML-прототип адвент-календаря на **31 день декабря 2026 года**.

3-колоночная Bento-сетка (1×1 и 2×1), стеклянные 3D-иллюстрации, события с короткими заголовками, советы на остальных днях и подробности в bottom sheet.

- **9 декабря — «Мандариновая вечеринка».**

## Возможности прототипа

- Все 31 дня декабря (13 событий из предоставленного пользователем HTML v5 и 18 дней с советами).
- Детальная шторка события или совета, время и место, мудрая мысль.
- Добавление в календарь через ICS, лайк, шаринг, локальное сохранение просмотров.
- Адаптивность для экранов 320–430 px, `prefers-reduced-motion`.
- CSS/JS/3D-изображения встроены в HTML; сборка и внешние зависимости не требуются.

## Развёртывание

GitHub Pages: **Settings → Pages → Build and deployment → Deploy from a branch → main / (root)**. После успешного развёртывания пути выше должны открываться автоматически. Прототипы также можно открыть как отдельные HTML-файлы.

## Данные

Точные номера переговорных и этажей не публикуются. **Время, места и описания по-прежнему демонстрационные** и не являются подтверждённым расписанием. Персональные данные сотрудников и закрытые материалы не включены. Прототип не является production-приложением.
