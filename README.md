# Декабрь чудес · Advent Calendar

Интерактивный мобильный HTML-прототип адвент-календаря на **31 день декабря 2026 года**.

3-колоночная Bento-сетка (1×1 и 2×1), стеклянные 3D-иллюстрации, события с короткими заголовками, советы на остальных днях и подробности в bottom sheet.

## Актуальная версия и границы разработки (решение 21 ноября 2026)

**Единственная рабочая версия — [`index.html`](index.html) / [Advent Calendar на GitHub Pages](https://hoseantonio85-art.github.io/advent-calendar/).** Дальнейшие UX/UI-правки и подготовка к интеграции выполняются **только в ней**. Она сейчас использует визуальный стиль Midnight Forest. Название темы — историческая метка, а не требование поддерживать несколько тем в продукте.

**Winter Glass, `compare.html` и каталог `versions/` — замороженные исторические материалы.** Они остаются в репозитории для просмотра и отката, но не получают новые функции, синхронизацию данных и обновления оформления. То, что альтернативная страница доступна на GitHub Pages, **не делает её частью продукта**.

**Объём поставки в мобильное приложение:** один актуальный интерфейс из `index.html`, только его необходимые ресурсы и код интеграции с существующим API/авторизацией приложения. Не переносить `winter-glass/`, `versions/`, `compare.html`, демо-переключатели дат или документацию как runtime-ресурсы. Способ упаковки (WebView/нативно) определяется при интеграции — копирование всего GitHub-репозитория запрещено как подход по умолчанию.

Последний раз обе темы обновлялись при создании v8 **до** этого уточнения. С этого момента поддерживается одна актуальная версия.

### Механика действий в текущем HTML

**Добавить в календарь**: браузер создаёт и скачивает файл `.ics` с полями события и демонстрационными данными; нативного открытия календаря/подтверждения записи нет. Дни без точного времени добавляются на весь день.

**Нравится**: личный переключатель в пределах этого браузера. Состояние сохраняется в `localStorage` по номеру дня, без сервера, общего счётчика, синхронизации или регистрации на событие. Посещения дат и сохранённые советы также локальные.

## Возможности прототипа

- Все 31 дня декабря (13 событий на основе HTML v5 и последующих пользовательских уточнений, 18 дней с советами).
- Детальная шторка события или совета, время и место, мудрая мысль.
- Добавление в календарь через ICS, лайк, шаринг, локальное сохранение просмотров.
- Адаптивность для экранов 320–430 px, `prefers-reduced-motion`.
- CSS/JS/3D-изображения встроены в HTML; сборка и внешние зависимости не требуются. С новыми иллюстрациями автономный HTML имеет размер около 1,2 МБ.

## Динамика календаря · v8 · 21 ноября 2026

- **Лайки** — фронтенд подготовлен к общему серверному счётчику; пока нет подключённого API, остаётся локальная демоверсия. В интерфейсе нет вымышленного общего числа.

**Интеграция с существующим бэкендом приложения:** [контракт лайков и настройки](docs/likes-api.md). GitHub Pages сам по себе не может вести общий счётчик. Для production потребуются API, идентификация пользователя на стороне приложения, HTTPS, права доступа и серверное хранение.

В активном `index.html` шторка **открытой даты** поддерживает свайп вниз от верхнего grabber: следует за пальцем, закрывается после протягивания на 100 px либо при быстром свайпе от 48 px; при коротком жесте возвращается на место. Для стабильного распознавания увеличена невидимая область полосочки до 32 px **без изменения визуальной композиции**. Обычная прокрутка текста не перехватывается. Старые способы закрытия крестиком, фоном и Escape сохранены.

Согласно прежнему решению шторку «Твоя история декабря» не меняли — свайп на ней пока не активируется; остальные темы/версии заморожены.

## Актуальный визуал замороженных карточек — прозрачный иней · 21 ноября 2026

После просмотра варианта 1 автор уточнил задачу: **заморозка должна быть намного легче, чтобы сквозь неё читались исходные карточки, а сетка не превращалась в одноцветную**.

- **Новый основной режим**: [лёгкий прозрачный иней](https://hoseantonio85-art.github.io/advent-calendar/?preview=1). На будущем совете остаётся **оригинальный фон** карточки — светлый бежевый/персиковый, тёмный зелёный, красный и их прежние вариации. Мороз проявляется тонкой холодной вуалью, подсвеченным бортиком и небольшими кристаллами в углах; центральная область и дата остаются чистыми.
- **Вариант 1 для сравнения**: [плотное голубое стекло](https://hoseantonio85-art.github.io/advent-calendar/?preview=1&frost=classic) — прежняя версия сохранена CSS-переключателем, без создания второй продуктовой темы.
- **Предыдущая мягкая проба**: [soft frost](https://hoseantonio85-art.github.io/advent-calendar/?preview=1&frost=soft) — тоже остаётся для дизайн-ревью.
- Три режима относятся **только к будущим датам с советами**; ни анонсы мероприятий, ни правило доступа к датам не изменены. Снежинки в левом верхнем углу, отсутствие замков и галочек, а также свайп для закрытия нижней шторки сохранены.
- В **Flutter** нужно перенести только выбранное в итоге визуальное состояние; query-параметры `preview` и `frost` — лишь HTML-инструменты сравнения.
- [Коммит с новой прозрачной заморозкой](https://github.com/hoseantonio85-art/advent-calendar/commit/86632f0cda21836cb27d1975fcb1602b390d6207).
