# Декабрь чудес · Advent Calendar

Интерактивный мобильный HTML-прототип адвент-календаря на **31 день декабря 2026 года**.

**Демо:** 3-колоночная Bento-сетка, карточки 1×1 и 2×1, цветные glass-3D-иллюстрации, события с короткими названиями, советы для остальных дней и подробности в bottom sheet.

## Запуск

Откройте [GitHub Pages](https://hoseantonio85-art.github.io/advent-calendar/) после настройки публикации либо скачайте `index.html` и откройте его в мобильном браузере.

Прототип автономный: CSS, JavaScript и иллюстрации встроены в HTML, установка зависимостей не требуется.

## Возможности

- Все 31 даты декабря; 10 демонстрационных событий и 21 день с советами.
- Детали события и мудрый совет в нижней шторке.
- Добавление события в календарь через ICS, лайк, отправка и сохранение просмотренных дней (локально в браузере).
- Адаптивность для iOS/Android и уменьшение анимации при `prefers-reduced-motion`.

## Публикация

Для первого запуска GitHub Pages в настройках репозитория выберите **Settings → Pages → Build and deployment → Deploy from a branch → main / (root)** и сохраните.

Все мероприятия, время, места и описания в **публичной версии вымышленные**, приведены только для демонстрации UX. Файл не содержит внутреннего расписания и данных сотрудников. Прототип не является production-приложением.
